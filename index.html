O que é a LetControl?
+

O LetControl é um sistema inteligente que monitora o consumo de água em tempo real, ajudando você a identificar desperdícios, economizar na conta e preservar recursos naturais.

Como faço para baixar o aplicativo?
+

O aplicativo está disponível para Android e pode ser baixado pelo link nesta página. Basta instalar o APK e seguir as instruções para parear com o sensor.

Como o sensor é instalado?
+

O sensor é instalado após a caixa d'água e se conecta ao app via Wi-Fi, enviando dados do consumo diretamente para o seu celular em tempo real. A instalação leva menos de 15 minutos.

Preciso de conhecimento técnico?
+

Não. A instalação é simples e pode ser feita por você mesmo. O aplicativo é intuitivo e guia você em cada etapa.

O LetControl detecta vazamentos?
+

Sim. O sistema analisa padrões de consumo e envia alertas quando detecta fluxo contínuo anormal ou variações que indicam possíveis vazamentos.
